# The Pregame

Clips, takes and scores for every game you follow.

This is the first version of the website. It uses sample teams and scores for now.

## Files
- `index.html` — the page and all five screens
- `styles.css` — the look (colors, fonts, layout)
- `app.js` — what happens when you tap things
- `manifest.webmanifest` and `icon.svg` — let people add the site to their phone's home screen
